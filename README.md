# EmailURLExtractor
Extract url from eml files in a folder, from QR, email attachment.

Download from release, the app for mac has below features. 

Extracts URLs from email text and HTML.

Extracts URLs from QR codes in image attachments.

Extracts URLs from PDF attachments (text, link annotations, and QR codes in images).

Shows From, To, Subject, Attachments.

Exports to Excel, with multiple URLs in a cell separated by line breaks.

Includes a progress bar for large folders.

Works with .eml files in a selected folder
